Энэ лаборторын ажлаар сурагчийн дүн болон ирцны байр байдал түүний нийлбэрийг олохоор java файл үүсгэн түүн дээрээ код бичээд оруулсан бөгөөд түүнийгээ тест буюу бүрэн ажиллагаатай аллдаатай ажилж байгаа эсэхийг шалгахаар тест бичсэн. Энэ дээр тест бичихдээ тухайн өөрийн бичсэн кодыг шалгах буюу ямар утга өгч яаж бичвэл миний кодны алдаа буюу цоорхой гарч ирэх боломжтой вэ гэдгийг харуулах гэж хичээсэн. Хичээлийн дүнгүүдийг A, B, C, D, F гэсэн байдлаар явагдаж мөн 0-100 хооронд байх хэрэгтэй болон буруу оролт дээр assertTrows маань үнэн ажилж байгаа эсэхийг шалгахаар тест дээр бичсэн. Тестийг шалгахдаа mvn test ашиглан ажлуулсан бөгөөд энгийн нэгжийн тест дээр 9 тест амжилттай ажилсан бол 2 ширхэг parametrized тест нэмэгдэх үедээ 21 тест болон нэмэгдсэн бөгөөд үүнээс харахад parameterized тест маань уншихдаа нэг тест биш тус бүрт нь уншиж байгааг ойлгосон. Дараагийн үедээ тест албаар fail болгох зорилготойгоор java код дотроо >=90 ийг >90 болгосон нь миний бичсэн тестийн 2ыг унагааж fail болгож байсан. Үүнээс би тест ногоон болсон гэдэг нь код зөв гэсэн үг биш, харин тест хязгаарыг үнэхээр шалгаж байгаа эсэхээс шалтгаална гэдгийг ойлгов.
